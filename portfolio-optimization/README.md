# Portfolio Risk Analysis

Built a portfolio optimization tool analyzing 5 stocks (BNS, TD, CNR, SHOP, BCE) using Python. Calculated Sharpe ratios, volatility, and efficient frontier to identify optimal asset allocation.

## Tools Used
- **Python**: yfinance, Pandas, NumPy, Matplotlib
- **Methodology**: Monte Carlo simulation, Modern Portfolio Theory

## Key Results
- Optimal portfolio identified via maximum Sharpe ratio
- Efficient frontier plotted showing risk-return tradeoff
- Individual stock metrics: annualized return, volatility, Sharpe ratio

## Files
- `portfolio_risk_analysis.py` — main analysis script
- `efficient_frontier.png` — output chart

- Financial data analysis
- Portfolio optimization
- Risk metrics calculation
- Data visualization
