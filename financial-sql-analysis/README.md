# Financial Data Analysis - SQL Case Study

SQL queries analyzing portfolio holdings, daily P&L, risk reporting, and rebalancing needs for a sample investment portfolio.

## Queries Included
1. Portfolio holdings summary by asset class
2. Daily P&L by sector
3. Top 10 best and worst performers (with window functions)
4. Risk reporting: portfolio volatility by asset class
5. Portfolio rebalancing needs (drift from target allocation)
6. Scenario analysis: impact of 1% yield increase on bond holdings

## Skills Demonstrated
- CTEs and subqueries
- Window functions (STDDEV, RANK, SUM over)
- JOINs across multiple tables
- CASE statements for conditional logic
- Scenario/risk analysis
- Portfolio attribution reporting
