# Fixed Income Analytics

Analyzed bond yield trends and calculated duration and convexity for a sample bond portfolio. Built visualizations showing yield curve shifts over time.

## Tools Used
- **Python**: yfinance, Pandas, NumPy, Matplotlib
- **Data**: US Treasury yields (3-month, 5-year, 10-year, 30-year)

## Analysis Performed
- Yield curve time series and slope analysis
- Current vs historical yield curve comparison
- Macaulay and Modified Duration calculation
- Bond convexity adjustment
- Price sensitivity to yield changes

## Files
- `fixed_income_analytics.py` — full analysis script
- `yield_curve_time_series.png` — historical yield chart
- `yield_curve_snapshot.png` — current vs year-ago curve
- `yield_curve_slope.png` — 10Y-5Y spread over time
